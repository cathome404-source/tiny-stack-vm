Entry secret-loader untuk bounty make.fun tiny-stack-vm: `main.ts` memuat implementasi VM lengkap dari entry secret `V` lewat `eval(process.env.V)`. Kode VM-nya sendiri tidak ada di repo ini — ia tinggal di secret, bukan di source.

Jalankan dengan:

```sh
MAKEFUN_INPUT_DIR=<input> MAKEFUN_OUTPUT_DIR=<output> node main.ts
```
